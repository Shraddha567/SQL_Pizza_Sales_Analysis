🍕 SQL Pizza Sales Analysis
📌 Project Overview

This project analyzes one year of pizza sales data to uncover key business insights using SQL and Google Sheets.
The goal is to evaluate sales performance, customer behavior, and product popularity to support data-driven decision-making.

🎯 Objectives
Analyze overall business performance using KPIs
Identify sales trends over time (daily & hourly)
Understand customer preferences by pizza category and size
Determine top-performing and underperforming products
📊 Key Performance Indicators (KPIs)
Total Revenue – Total sales generated
Average Order Value – Average amount spent per order
Total Pizzas Sold – Total quantity of pizzas sold
Total Orders – Number of unique orders placed
Average Pizzas per Order – Average pizzas per order
